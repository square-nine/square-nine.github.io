This is the first post I've made to this blog. I might date prior events past this when I recap important moments in my life, but I assure you that this is the first.

## Why?

At first, making a website seems daunting. Finding a place to set it up, developing the skills to maintain it as well as keeing it in check are all lengthy things for something that could easily be replaced by a single text document. And I don't think I know the answer myself! I created this website because I always wanted a site of my own, to freely express who I am in all my unique ways. I've got no shame in expressing my feelings online - just my personal moments.

I've also been partly exposed to the power of journaling. As someone who barely uses paper, why not make my journals public? If I stumble upon anything important to anyone else I might as well have had it online, no?

I chose Github Pages because 1) it's free, 2) full control of code and 3) did I mention it's free?. If I wanted a sick-ass name for my blog then I'll have to pay for it, but until then I'll stick with this one. It's great when my side projects turn out free!

## How?

Blood, sweat and tears. I'm kidding, it really isn't too hard to make a website nowadays. With the advent of AI, making a website is even easier! Nevertheless I found a complicated way of making it.

### Step 1: Fail
I originally tried making this last year. With no AI, I intended to follow a blueprint to the letter and make it work. I picked out a lovely template (the one you see now, "Chirpy") and chugged along with the guide. I don't quite remember where I found it, but I most likely searched for "how to make Github pages website".

It failed. Miserably. For some reason nothing would preview, and I found it hard to install the software to help test it locally. It really bummed me, and so I dropped this

### Step 2: Call upon your digital friend
Firstly, the AI I used is Claude, on the free plan. For "simple" things it's really not needed to use it more. And I promise to keep my blog with as minimal AI usage as possible.

With this tool, I went back to this repository and consulted Claude with the simple prompt "Help me make this run". And it did. The error was so bleedingly simple!

My username, `square_nine` is not actually compliant with Github's username policies. So I use `square-nine`. When creating my Github Pages repository last year I called it `square_nine.github.io`. In order for it to display without extra tinkering, I needed the username to match the front. So, one issue: literally `_` vs `-`. LOL. Now that's fixed, the website is here as you see it!
